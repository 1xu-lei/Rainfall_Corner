# 部署与运行入口 — 启动说明

> 作品：**雨落街角 / Rainfall Corner**
> 成员：**徐磊**、**杨海涛**
> 运行环境：Windows 10 / 11（本机开发与验收环境为 Windows，1440×900 分辨率最佳）

---

## 1. 环境依赖

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18（实测 v26.13.1） | 前端构建与开发服务器；`npm` 随 Node 安装 |
| Python | ≥ 3.10（实测 3.14.5） | 后端 API；安装时请勾选 “Add Python to PATH” |
| 浏览器 | Edge / Chrome（近两年版本） | 界面为桌面端优先，建议 1440×900 以上 |
| 网络 | 首次安装依赖需要 | 之后完全离线可运行（无外链、无 CDN 字体） |

> 无需数据库安装：后端使用 SQLite，首次启动自动在 `backend/rainfall.db` 建库。

---

## 2. 一键启动（推荐，评委路径）

1. 解压提交包到**英文路径**（例如 `D:\RainfallCorner`），避免中文路径带来的编码问题；
2. 双击根目录 **`启动.bat`**（`01_项目代码` 内的同名文件也可）；
3. 脚本会依次：
   - 检查/创建 `backend\.venv` 并安装 `backend\requirements.txt`；
   - 检查 `frontend\node_modules`，缺失则执行 `npm install`；
   - 在新窗口启动后端（`http://127.0.0.1:8000`）与前端（`http://localhost:5199`）；
   - 8 秒后自动打开浏览器。
4. 关闭弹出的两个命令行窗口即停止服务。

首次启动耗时约 1–3 分钟（主要花在 `npm install`），之后约 10 秒。

---

## 3. 手动启动（两条命令）

```bat
:: ① 后端（仓库根目录执行）
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000

:: ② 前端（另开一个窗口，仓库根目录执行）
npm --prefix frontend install      :: 仅首次
npm --prefix frontend run dev      :: http://localhost:5199
```

若 `npm` 不在 PATH：

```bat
set "PATH=C:\Program Files\nodejs;%PATH%"
```

首次使用后端前，若没有虚拟环境：

```bat
py -3 -m venv backend\.venv
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

## 4. 端口与地址

| 服务 | 默认地址 | 修改方式 |
|---|---|---|
| 前端（开发） | `http://localhost:5199` | `npm --prefix frontend run dev -- --port 5200` |
| 前端（生产构建预览） | `http://localhost:4173` | `npm --prefix frontend run build` 后 `npm --prefix frontend run preview` |
| 后端 API | `http://127.0.0.1:8000` | `uvicorn ... --port 8010` + 前端 `set VITE_API_BASE=http://127.0.0.1:8010` |

后端已放行前端来源：`5199 / 5200 / 5301 / 4173`（`backend/app/main.py` 的 `ALLOWED_ORIGINS`）。

## 5. 验证清单（跑通即说明环境正常）

```bat
:: 1) 后端 32 项测试（含 126 组合 × 2 雨型 = 252 次全枚举）
backend\.venv\Scripts\python.exe -m pytest -q
:: 期望：32 passed

:: 2) 前端类型检查 + 生产构建
npm --prefix frontend run typecheck
npm --prefix frontend run build
:: 期望：均 exit 0

:: 3) 前后端引擎一致性（252 组逐字段比对）
node frontend\scripts\check-engine-parity.mjs
:: 期望：parity rows=252 mismatched=0

:: 4) 接口连通
curl http://127.0.0.1:8000/api/health
:: 期望：{"status":"ok","rulesVersion":"rain-five-v1","engine":"rule-based"}
```

界面自检（3 分钟）：

1. 打开 `http://localhost:5199`；
2. 右上角应显示数据源（首次进入为「本地预览引擎」，完成一次推演后显示「后端引擎」）；
3. 右栏点「清空」→ 分配 学校 1 / 集市 1 / 公园 3 / 居民区 0 / 车站 0 → 点「开始推演」；
4. 结算页应显示 **83 分 / A 级 / 偏科型 / 触发「上游调蓄」**（与后端 126 组合实测一致）；
5. 返回调整 → 换「短时强降雨」用同一套分配再推一次 → 分数应变低（实测 73.6），说明雨型真正参与计算。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击后中文显示为乱码 | 脚本为 GBK 编码，请在**中文（简体）区域设置**的 Windows 上运行；或在 cmd 中先执行 `chcp 936` |
| 提示 `python 不是内部或外部命令` | Python 未加入 PATH：重装并勾选 “Add Python to PATH”，或把 `Python3xx` 目录加入 PATH |
| 提示 `npm 不是内部或外部命令` | 安装 Node.js 后，`启动.bat` 已自动把 `C:\Program Files\nodejs` 前置到 PATH；若装在别处请改脚本第 12 行 |
| 前端能开但显示「本地预览引擎」 | 后端没起来：看后端窗口是否有报错；后端未启动时前端会降级到本地引擎，流程仍可完整演示 |
| 8000 端口被占用 | `uvicorn ... --port 8010`，并给前端 `set VITE_API_BASE=http://127.0.0.1:8010` |
| 5199 被占用 | `npm --prefix frontend run dev -- --port 5200`（后端已放行该来源） |
| `npm install` 很慢或失败 | 换用国内镜像：`npm config set registry https://registry.npmmirror.com` 后重试 |
| 页面空白 | 确认浏览器不是 IE；F12 看 Console，通常是后端 CORS 来源未放行或端口不匹配 |
